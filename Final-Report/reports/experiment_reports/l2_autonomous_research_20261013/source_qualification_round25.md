# L2 source discovery follow-up — round 25

## Scope boundary

This was a first-party publication/repository metadata screen for independent L2 jailbreak sources after the round12 source-concentration diagnosis and the R24 WUSTL experiment. No candidate files or prompt rows were opened, downloaded, or used. No model fit, parameter sweep, test access, L3, cascade, or smoke task occurred.

## Decision

No new source is admitted and no additional L2 run is justified by this screen. The strongest metadata leads fail the current single-turn, non-synthetic, rights/lineage, or access requirements.

## L2 implication

R06 remains the only current package with a newly added publisher-level JB collection outside the TrustAIR source. Its held-out WUSTL family produced a useful local recall/precision signal, but the full validation and pooled OOF metrics did not improve. JBC/manual is already held out for validation and has shared community ancestry; MallaJailbreak cannot be admitted without a data-rights and observation-unit basis; MHJ would require a different multi-turn task contract; the MLCommons public artifact is a taxonomy rather than reusable benchmark prompt data; the other current leads are synthetic, mixed, gated, or PI-like.

The next useful work is first-party discovery of an openly usable, standalone, human-authored JB-attempt train source and completion of source rights/privacy/lineage evidence for already admitted provisional data. Do not retune on R05/R06. Keep the official status NOT_READY / GATE_UNSPECIFIED, test family metadata only, and L3 out of scope.
