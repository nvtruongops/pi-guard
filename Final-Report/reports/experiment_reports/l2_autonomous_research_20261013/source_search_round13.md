# Source/family coverage research — round 13

## Scope boundary and method

This was a metadata-only review of public dataset cards and source repositories to find independent English source families that could address the round12 L2 OOF coverage pattern. No dataset file was downloaded or opened and no candidate row was used in a run. One Hugging Face search-result preview exposed a few snippets from S-Labs' public upstream `test.csv`; those snippets were excluded from source selection and modeling, and that upstream test is treated as closed for this task. PI-Guard's sealed test payload was not accessed. No source was added to a package. Publisher-card statements below are leads for qualification, not local validation or legal approval.

## Research conclusion

No candidate in this metadata-only pass clears the project source-family and rights/privacy gates. `jackhhao` is the most relevant next source to qualify because its publisher-facing labels include benign and jailbreak under a stated Apache-2.0 license, but the missing row ancestry, family, privacy, and dataset-construction evidence still prevents admission. `S-Labs` and Lakera could diversify PI/benign or PI-only support, respectively, but neither alone resolves the JB source gap. These are candidate leads, not approvals.

The result supports stopping additional model sweeps on the frozen package for now. Continue source qualification at the original-publisher level and create a new dataset version only if source/family overlap, native-label compatibility, rights, and privacy evidence all pass. Keep official L2 acceptance `GATE_UNSPECIFIED`; do not open test payload or run L3/smoke.

As methodological context only, a 2026 arXiv preprint reports an 8.4-percentage-point AUC gap between standard same-source splits and leave-one-dataset-out evaluation across its 18-dataset benchmark, and identifies dataset-dependent shortcuts among learned features. Its model setup and task mix differ from PI-Guard; this is not a PI-Guard metric or evidence that this particular TF-IDF model has the same effect. It supports treating source-held-out evidence as a distinct research question ([Fomin, 2026](https://arxiv.org/abs/2602.14161)).
