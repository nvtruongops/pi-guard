# Autonomous English L2 research continuation

## Scope Boundary Declaration

Source task: the attached L2 goal and latest user clarifications. The user authorized native labels or reproducible mappings as research references without waiting for curator approval; they remain distinct from curator-reviewed canonical labels. This task ends at L2. No L3 analysis, training, evaluation, or handoff is required here.

IN-SCOPE: English-only source/provenance research; versioned train/validation data preparation; privacy and duplicate audits; the fixed L2 baseline and justified L2-only experiments; validation, source-family diagnostics, latency where specified, and an evidence-based L2 readiness report.

OUT-OF-SCOPE: L3 analysis/training/deployment, cascade execution, changing old datasets or V8 locked evaluations, claiming human review that did not happen, hidden label inference, fabricated or assistant-generated prompts, opening or using any final-test payload, commits or publication. The approved final-test contract exposes family-level metadata only; row identifiers, text and payload remain sealed.

Current data constraint: the previous round06/r03 package and its metrics are historical only. CiberIA v1 and 3nesdeniz are synthetic sources, and Wambo prompts are LLM-generated; none may enter a new L2 train or validation package. TrustAIR and individually qualified NeurAlchemy components may be reconsidered only after their source, label mapping, rights, privacy, and split roles are recorded.

**Role: L2 Research & Engineering Agent.** Improve the L2 data/training pipeline using traceable real data and versioned, isolated experiments. Change only L2 code in this task; fit and assess L2 with full train/validation runs and source-family-held-out evidence.

**Never create or run a smoke task, smoke mode, shortened training run, or tiny sampled fit.** Verify code and data contracts with static/schema/integrity checks, then run the complete, uniquely named L2 experiment. Do not implement, train, evaluate, or invoke L3 or the cascade. Keep all test row IDs, text and payload sealed.

## Chosen implementation

Reuse the existing pure model/evaluation helpers instead of duplicating TF-IDF or routing code. Keep fit_l2_v8.py and historical datasets byte-identical. Add fit_l2_curated.py beside it, accepting an explicit new package and unique output. Candidate packages produce a BLOCKED JSON without reading row payloads. A frozen research package must provide row-level source/label evidence, excluded/held IDs, train/validation split assignments and hashed train/validation paths. Test is represented only by the approved family-level aggregate contract; the adapter never loads test payloads.

Tests use existing real candidate metadata and blank annotation files. Metadata-only negative cases can be checked in memory; no test creates labeled examples or fake model metrics. A positive fit-path claim requires a qualifying real dataset and is not inferred from these negative checks.
