# L2 source qualification — round 19

## Scope Boundary Declaration

This is a metadata and primary-document screen for a non-TrustAIR, non-synthetic, human-authored jailbreak-attempt source for L2 training. It does not add data, establish curator-canonical labels, change a package or split, inspect dataset rows or locked evaluation payloads, run training, smoke work, L3, or a cascade. Public source labels are treated only as references.

## Decision

**No source is admitted to the L2 train/validation package from this screen.** None of the examined primary-source releases documents all required gates together: native jailbreak-attempt meaning for released human-authored rows, source independence from TrustAIR/JailbreakHub, source/family and duplicate lineage, applicable reuse rights, collection/privacy treatment, and an eligible train/validation role. The user-provided L2 data gate also requires at least two independent train families per class and a separate family for validation and test per class; this screen supplies no qualified JB train family toward that coverage. This is a negative qualification result, not evidence that no such dataset exists.

## L2 consequence

Do not change the existing L2 package or run a training experiment from these leads. JailbreakDB could be reconsidered only after primary, source-specific documentation proves human authorship and reuse rights, privacy/collection clearance, duplicate/family grouping, and an eligible train/validation subset. The USENIX participant study would need an explicit release of participant-created prompts separated from online and AI-assisted material, plus the same gates. Even then, one qualifying JB source would not alone meet the minimum two independent train-family requirement for JB or supply the separately held-out validation and test families. JailbreaksOverTime cannot repair the source-independence gap while its documented attack lineage remains JailbreakChat/JailbreakHub.

This round does not change the existing readiness decision: **L2 remains NOT_READY / GATE_UNSPECIFIED** under the current owner declaration. No L3 work is indicated or performed.
