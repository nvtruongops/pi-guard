# ModernBERT reference package

**Status (2026-09-29): no local prompt-injection model result is retained.** The former 10-row project probe fed a whitespace/regex simulation; the runner did not load ModernBERT’s tokenizer or weights. The probe and derived outputs were removed, and the legacy simulation runner is disabled.

Paper: Warner et al., *ModernBERT: Bringing Modern Transformer Innovations to Pre-trained Encoders* (2024), arXiv:2412.13663.

Model/source: https://huggingface.co/answerdotai/ModernBERT-base and https://github.com/AnswerDotAI/ModernBERT. These assets remain reference material.
