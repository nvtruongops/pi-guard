# Dataset status — InstructDetector

No project-local proxy evaluation set is retained. The previous `bipia_text_eval.json` and `bipia_code_eval.json` subsets lacked verified record-level mapping and split equivalence to the official BIPIA release; they and the TF-IDF proxy outputs were withdrawn on 2026-09-29.

The upstream InstructDetector repository and its native data files remain reference material. A future evaluation must document the exact BIPIA source files, split, labels, and model implementation. The paper appeared in Findings of EMNLP 2025.
