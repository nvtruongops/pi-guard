# InstructDetector reference package

Paper: Wen et al., *Defending against Indirect Prompt Injection by Instruction Detection*, Findings of EMNLP 2025, DOI `10.18653/v1/2025.findings-emnlp.1060`.

The former project-local BIPIA subsets and TF-IDF/Logistic Regression outputs were withdrawn because row-level source mapping and evaluation-split equivalence were not verified. The local proxy runner is disabled; its method did not implement InstructDetector’s hidden-state/gradient detector.

The upstream code and paper references remain for study. No empirical result for InstructDetector is retained in this folder.
