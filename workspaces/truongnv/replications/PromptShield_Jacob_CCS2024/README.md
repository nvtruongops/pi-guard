# PromptShield reference and evaluation assets

Paper: Dennis Jacob et al., *PromptShield: Deployable Detection for Prompt Injection Attacks*, CODASPY 2025, DOI `10.1145/3714393.3726501`, arXiv:2501.15145.

The upstream package retains the author’s 23,369-record camera-ready English evaluation benchmark. The project-authored 20-row TF-IDF subset and its resubstitution outputs were removed because they did not evaluate PromptShield. The local proxy runner is disabled.

For the separately audited ProtectAI checkpoint comparison on this benchmark, see [the reproduction audit](../../reports/experiment_reports/reproduction_audit_2026-09-29/EXPERIMENT_REPRODUCTION_AUDIT.md). Dataset identity and hash are listed in [dataset provenance](datasets/DATASET_PROVENANCE.md).
