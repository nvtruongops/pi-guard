# Retired cross-paper suite

This suite combined classifier checkpoints and datasets originating from different papers. Its local model/data comparisons and derived metrics are withdrawn under the paper-origin rule, even where source snapshots or arithmetic checks remain available. Do not run the retired preparation workflow or cite its outputs.

The source files, derived splits, predictions, reports, and dependent figures are still undergoing cleanup; this README does not certify that they have all been deleted. See the [withdrawn-artifact register](../../WITHDRAWN_DATA_ARTIFACTS.md) and [workspace provenance audit](../../../experiment_reports/WORKSPACE_PROVENANCE_AUDIT_2026-09-30.md) for current disposition.
