# WITHDRAWN — historical cross-paper public-source suite

The files in this old suite were assembled from multiple public sources and paired with checkpoints from separate paper releases. Their local metrics are withdrawn under the user's same-paper rule. Public source hashes do not validate the model/data protocol. Automatic approval review blocked deletion, so any residual files must not be run or cited.
