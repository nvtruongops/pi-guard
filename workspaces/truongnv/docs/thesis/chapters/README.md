# Thesis Chapters 1–2

These are the current working drafts of the first two thesis chapters:

1. [Chapter 1 — Introduction](01_Introduction.md): research background, problem statement, registered objectives, significance, scope, limitations, and thesis structure.
2. [Chapter 2 — Literature Review](02_Literature_Review.md): attack studies, benchmarks, detection approaches, synthesis, and the project’s planned contribution.

## Reading and evidence boundaries

- The chapter structure follows the read-only [official FPT IAP491 guide](../../../../../docs/fpt_capstone_guide/IAP491_CP_StudentsGuideForm%20for%20Research%20Based%20Thesis.docx).
- Project-specific objectives link to the read-only [Capstone Project Register](../../../../../CAPSTONE%20PROJECT%20REGISTER.md).
- Paper citations use numbered anchors from the local [References Log](../../../References/REFERENCES_LOG.md), with local PDFs linked in each chapter.
- The Review 1 report folders are historical references, not the current chapter text. Review 2 work remains tracked in [tasks_for_review2](../../../reports/tasks_for_review2/README.md); the other report folders are reference material.
- The chapters separate published findings from project objectives. They do not present the objectives as completed implementation or measured performance.
